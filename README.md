# LogWell demo

Public demonstration of [MAE Bridge](https://maebridge.com) LogWell: structured log search, error correlation, and diagnostic analysis.

All data is synthetic. Safe for anonymous recruiter and client review — no production systems.

## Live demo

- https://maebridge.com/work/logwell

## Run locally

Serve this folder with any static file server, for example:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Contents

| File | Role |
| --- | --- |
| `index.html` | Demo shell and landing |
| `demo.js` | Synthetic events, search UI, guided walkthrough |
| `styles.css` | Demo styles |
| `favicon.png` | Favicon |
